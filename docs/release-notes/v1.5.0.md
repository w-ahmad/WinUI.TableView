# v1.5.0

> **Stable Release** · September 16, 2026 · [NuGet](https://www.nuget.org/packages/WinUI.TableView/1.5.0) · [GitHub Release](https://github.com/w-ahmad/WinUI.TableView/releases/tag/v1.5.0)

## 🌟 Features

* Added `CellWithRow` selection mode to select the clicked cell while keeping the full row highlighted by [@w-ahmad](https://github.com/w-ahmad) in [#388](https://github.com/w-ahmad/WinUI.TableView/pull/388)
* Added drag selection rectangle for multi-cell selection by [@godlytalias](https://github.com/godlytalias) in [#344](https://github.com/w-ahmad/WinUI.TableView/pull/344)
* Added clipboard paste support (`CanPaste`, `Pasting` event, and paste command) by [@w-ahmad](https://github.com/w-ahmad) in [#379](https://github.com/w-ahmad/WinUI.TableView/pull/379)
* Added `ColumnAutoWidthMode` to auto-size columns to their content by [@Mangepange](https://github.com/Mangepange) in [#361](https://github.com/w-ahmad/WinUI.TableView/pull/361)
* Added support for inline cell templates in `TableViewTemplateColumn` by [@w-ahmad](https://github.com/w-ahmad) in [#360](https://github.com/w-ahmad/WinUI.TableView/pull/360)
* Added Native AOT compatibility by [@w-ahmad](https://github.com/w-ahmad) in [#352](https://github.com/w-ahmad/WinUI.TableView/pull/352)
* Added UI Automation and accessibility support with automation peers for the TableView, cells, rows, column headers, and row headers by [@w-ahmad](https://github.com/w-ahmad) in [#397](https://github.com/w-ahmad/WinUI.TableView/pull/397)
* Added multi-level column grouping support on Windows with `GroupDescriptions`, `RefreshGrouping()`, and sort-by-count support by [@w-ahmad](https://github.com/w-ahmad) in [#425](https://github.com/w-ahmad/WinUI.TableView/pull/425)
* Added `ShowSortableColumnIcon` to optionally display a hint icon on sortable columns by [@w-ahmad](https://github.com/w-ahmad) in [#427](https://github.com/w-ahmad/WinUI.TableView/pull/427)

## Enhancements

* Added `ColumnResizeMode` with `Live` and `Preview` modes for a smoother column resizing experience by [@w-ahmad](https://github.com/w-ahmad) in [#420](https://github.com/w-ahmad/WinUI.TableView/pull/420)
* Improved drag selection to allow selection gestures to start from rows and empty space, not only individual cells, by [@w-ahmad](https://github.com/w-ahmad) in [#417](https://github.com/w-ahmad/WinUI.TableView/pull/417)
* Improved keyboard navigation with better Tab, Enter, and arrow-key handling across cells by [@Mangepange](https://github.com/Mangepange) in [#356](https://github.com/w-ahmad/WinUI.TableView/pull/356)
* Added `OperationContentBinding` to `TableViewTemplateColumn` for sorting, filtering, and export support by [@Mangepange](https://github.com/Mangepange) in [#356](https://github.com/w-ahmad/WinUI.TableView/pull/356)
* `TableViewTemplateColumn` now uses `ClipboardContentBinding` for copy and export operations by [@Mangepange](https://github.com/Mangepange) in [#355](https://github.com/w-ahmad/WinUI.TableView/pull/355)
* Extended compiled binding paths to support mixed collections and subclass hierarchies by [@DanielTrommel](https://github.com/DanielTrommel) in [#382](https://github.com/w-ahmad/WinUI.TableView/pull/382)
* Added an option to select a cell or row when its context menu is triggered by [@cricketthomas](https://github.com/cricketthomas) in [#374](https://github.com/w-ahmad/WinUI.TableView/pull/374)
* Migrated the library source to C# 14 and the `field` keyword by [@w-ahmad](https://github.com/w-ahmad) in [#375](https://github.com/w-ahmad/WinUI.TableView/pull/375)
* Improved memory management and lifecycle handling for `TableView` by [@w-ahmad](https://github.com/w-ahmad) in [#369](https://github.com/w-ahmad/WinUI.TableView/pull/369)
* Allowed selector-only `TableViewTemplateColumn` instances to enter edit mode by [@w-ahmad](https://github.com/w-ahmad) in [#400](https://github.com/w-ahmad/WinUI.TableView/pull/400)
* Default date and time formats are now derived from the user's locale by [@w-ahmad](https://github.com/w-ahmad) in [#401](https://github.com/w-ahmad/WinUI.TableView/pull/401)
* Added Persian (`fa-IR`) translations by [@ghost1372](https://github.com/ghost1372) in [#402](https://github.com/w-ahmad/WinUI.TableView/pull/402)
* Updated the Windows App SDK target from 1.6 to 1.8 by [@licon4812](https://github.com/licon4812) in [#285](https://github.com/w-ahmad/WinUI.TableView/pull/285)
* Updated Uno.SDK and Uno.WinUI dependencies by [@w-ahmad](https://github.com/w-ahmad) in [#405](https://github.com/w-ahmad/WinUI.TableView/pull/405)

## Fixes

* Fixed a Native AOT `XamlParseException` when opening the column filter flyout by [@w-ahmad](https://github.com/w-ahmad) in [#432](https://github.com/w-ahmad/WinUI.TableView/pull/432)
* Fixed column reordering so an incomplete reorder operation is cancelled when pointer capture is lost by [@Mangepange](https://github.com/Mangepange) in [#408](https://github.com/w-ahmad/WinUI.TableView/pull/408)
* Fixed null clipboard payload handling by [@mavaddat](https://github.com/mavaddat) in [#305](https://github.com/w-ahmad/WinUI.TableView/pull/305)
* Fixed editing state when `IsReadOnly` changes on the `TableView` or a column by [@Mangepange](https://github.com/Mangepange) in [#389](https://github.com/w-ahmad/WinUI.TableView/pull/389)
* Fixed stale edit states by ending editing on pointer press by [@Mangepange](https://github.com/Mangepange) in [#357](https://github.com/w-ahmad/WinUI.TableView/pull/357)
* Fixed a column width regression introduced by the C# 14 refactor and `ColumnAutoWidthMode` changes by [@DanielTrommel](https://github.com/DanielTrommel) in [#386](https://github.com/w-ahmad/WinUI.TableView/pull/386)
* Fixed column auto-sizing by ensuring cells are measured when their element is set by [@w-ahmad](https://github.com/w-ahmad) in [#372](https://github.com/w-ahmad/WinUI.TableView/pull/372)
* Fixed filter flyout search behavior using the custom `MenuFlyout` control by [@w-ahmad](https://github.com/w-ahmad) in [#378](https://github.com/w-ahmad/WinUI.TableView/pull/378)
* Fixed column reordering to require a valid drop target and prevented duplicate header option commands by [@w-ahmad](https://github.com/w-ahmad) in [#352](https://github.com/w-ahmad/WinUI.TableView/pull/352)
* Fixed date/time column formatting with platform-specific `ClockIdentifier` handling by [@w-ahmad](https://github.com/w-ahmad) in [#404](https://github.com/w-ahmad/WinUI.TableView/pull/404)
