# v1.5.0-preview2

> **Preview Release** · August 29, 2026 · [NuGet](https://www.nuget.org/packages/WinUI.TableView/1.5.0-preview2) · [GitHub Release](https://github.com/w-ahmad/WinUI.TableView/releases/tag/v1.5.0-preview2)

## 🌟 Features

- Added multi-level column grouping support (Windows only) with `GroupDescriptions`, `RefreshGrouping()`, and sort-by-count option by [@w-ahmad](https://github.com/w-ahmad) in [#425](https://github.com/w-ahmad/WinUI.TableView/pull/425)
- Added `ShowSortableColumnIcon` option to display a hint icon on sortable columns by [@w-ahmad](https://github.com/w-ahmad) in [#427](https://github.com/w-ahmad/WinUI.TableView/pull/427)

## Enhancements

- Added `ColumnResizeMode` property (Live / Preview) for smoother column resize experience by [@w-ahmad](https://github.com/w-ahmad) in [#420](https://github.com/w-ahmad/WinUI.TableView/pull/420)
- Allow drag selection to start from rows and empty space by [@w-ahmad](https://github.com/w-ahmad) in [#417](https://github.com/w-ahmad/WinUI.TableView/pull/417)

## Fixes

- Fix: Cancel drop on `PointerCaptureLost` during column reordering by [@Mangepange](https://github.com/Mangepange) in [#408](https://github.com/w-ahmad/WinUI.TableView/pull/408)
