# v1.5.2

> **Stable Release** · November 18, 2026 · [NuGet](https://www.nuget.org/packages/WinUI.TableView/1.5.2) · [GitHub Release](https://github.com/w-ahmad/WinUI.TableView/releases/tag/v1.5.2)

WinUI.TableView v1.5.2 is a maintenance release focused on stability when a `TableView` is unloaded and reloaded, selection behavior, star column sizing, and column reordering. This update also adds Uno Platform 7 support and improvements to the sample application and documentation.

## 🐛 Fixes

- Fixed a "Layout cycle detected" crash when expanding row details that contain a horizontally scrolling `ScrollViewer` wider than the table, in a `TableView` with unbounded height by [@w-ahmad](https://github.com/w-ahmad) in [#464](https://github.com/w-ahmad/WinUI.TableView/pull/464).
- Fixed rows disappearing when a `TableView` is shown in a `ContentDialog` or is re-parented in the visual tree. A late `Unloaded` event raised while the control is still loaded no longer empties the rows by [@w-ahmad](https://github.com/w-ahmad) in [#465](https://github.com/w-ahmad/WinUI.TableView/pull/465).
- Fixed an `ArgumentOutOfRangeException` in `ScrollRowIntoView` that could terminate the app when items were removed right after a single-row selection by [@w-ahmad](https://github.com/w-ahmad) in [9ff1270](https://github.com/w-ahmad/WinUI.TableView/commit/9ff12707bba920395c8bbddb3110b949454394a2).
- Fixed star (`*`) column widths not being recalculated when a column is hidden, which left an empty gap where the hidden column had been by [@AsafMah](https://github.com/AsafMah) in [#473](https://github.com/w-ahmad/WinUI.TableView/pull/473).
- Fixed the selection being lost when a `TableView` is unloaded, such as on a tab switch in a `TabView`, which also pushed `null` into a two-way bound `SelectedItem`. The selection and vertical scroll position are now kept across unload and reload by [@w-ahmad](https://github.com/w-ahmad) in [#490](https://github.com/w-ahmad/WinUI.TableView/pull/490).
- Fixed Shift+Click range selection extending from a stale anchor instead of the last clicked row, and doing nothing on cells in the `Cell`, `CellOrRow` and `CellWithRow` selection units. Ctrl+Shift+Click continues to add the range to the existing selection by [@w-ahmad](https://github.com/w-ahmad) in [#493](https://github.com/w-ahmad/WinUI.TableView/pull/493).
- Fixed cells no longer following the header width after a column header was dragged and dropped back on its own slot. A drop that moves nothing no longer raises `ColumnReordering` / `ColumnReordered` or clears the selection by [@w-ahmad](https://github.com/w-ahmad) in [#494](https://github.com/w-ahmad/WinUI.TableView/pull/494).
- Fixed star (`*`) columns never reaching the right edge of the `TableView`, leaving a 32 px gap after the last cell. Star widths are now recalculated when the border, padding, headers or grid lines change by [@w-ahmad](https://github.com/w-ahmad) in [#496](https://github.com/w-ahmad/WinUI.TableView/pull/496).
- Fixed rows keeping outdated cells when a column was shown, hidden, moved or resized while the table was empty, which could also throw an `ArgumentOutOfRangeException` when a cell in the affected column became the current cell by [@w-ahmad](https://github.com/w-ahmad) in [#497](https://github.com/w-ahmad/WinUI.TableView/pull/497).
- Fixed column headers and the select-all checkbox not lining up with the cells and row checkboxes when `Padding` is set on the `TableView` by [@w-ahmad](https://github.com/w-ahmad) in [#498](https://github.com/w-ahmad/WinUI.TableView/pull/498).

## Enhancements

- Added Uno Platform 7 support. The `net10.0` target is now built against `Uno.WinUI` 7, while the `net9.0` and `net8.0` targets continue to use Uno Platform 6 by [@w-ahmad](https://github.com/w-ahmad) in [#492](https://github.com/w-ahmad/WinUI.TableView/pull/492).

## 🧪 Testing and Maintenance

- Fixed the WebAssembly sample application failing to start after the Uno Platform 7 upgrade by re-recording its AOT profile, and reduced the size of its native binary by [@w-ahmad](https://github.com/w-ahmad) in [#495](https://github.com/w-ahmad/WinUI.TableView/pull/495).
- Removed the `CommunityToolkit.WinUI.Controls.SettingsControls` dependency from the sample applications, which is not compatible with Uno Platform 7 by [@w-ahmad](https://github.com/w-ahmad) in [#492](https://github.com/w-ahmad/WinUI.TableView/pull/492).
- Added Star Columns and Column Reorder pages to the sample application, and expanded test coverage for selection, lifecycle, star column sizing and column reordering on both WinUI and Uno Platform.
- Added a NuGet publish step to the CD build workflow.

## Documentation

- Added Samples App links (Microsoft Store and live Uno WASM) to the documentation top navigation by [@w-ahmad](https://github.com/w-ahmad) in [#491](https://github.com/w-ahmad/WinUI.TableView/pull/491).
